# Native app screenshots

The iPhone dialler and the Apple Watch app are native, so they can't be captured from a web build like the other
screens. Put their screenshots here, with exactly these names (PNG, JPG or WebP):

- `iphone-dialler.png` - an iPhone screenshot of the dialler (a call with the client's file on screen is ideal)
- `apple-watch.png` - an Apple Watch screenshot of a call

The Mobile apps page picks them up automatically on the next build and shows them in a device frame in place of the
drawings. Use sample data only (no real clients or phone numbers). Plain screenshots straight from the device are
fine; keep each under about 500 KB.
